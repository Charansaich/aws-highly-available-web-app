# 🚀 Highly Available Web Application on AWS

## 📌 Project Overview

This project demonstrates deployment of a highly available and scalable web application using AWS.

## 🧠 Architecture

User → Load Balancer → EC2 Instances (Auto Scaling)

## 🛠️ Services Used

* Amazon EC2
* Application Load Balancer
* Auto Scaling Group
* Amazon VPC
* Security Groups
* AMI

## ⚙️ Features

* High availability
* Fault tolerance
* Auto scaling
* Load balancing

## 🔧 Steps Performed

1. Created EC2 instance and installed Apache
2. Deployed web page
3. Created AMI
4. Configured Load Balancer
5. Created Auto Scaling Group
6. Tested fault tolerance

## 🎯 Outcome

Successfully built a scalable and highly available cloud architecture.
